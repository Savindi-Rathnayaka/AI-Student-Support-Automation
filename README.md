# 🎓 AI-Powered Student Support Automation System

## 📌 Project Overview

This project is an AI-powered student support automation system built using n8n and Google Sheets. It helps students receive simple, understandable answers to their academic questions through an automated workflow.

## 🎯 Project Objectives

* Automate responses to student questions using AI.
* Explain academic topics in simple English.
* Store student questions and AI-generated answers in Google Sheets.
* Reduce repetitive manual work in student support.

## 🛠️ Technologies Used

* **n8n** – Workflow automation
* **AI Language Model** – Generates student-friendly answers
* **Google Sheets** – Stores questions and answers

## ⚙️ How It Works

1. A student submits their name and question through a form.
2. n8n receives the submitted information.
3. The Edit Fields node organizes the input data.
4. The Basic LLM Chain generates an answer using AI.
5. Google Sheets stores the student's question and generated answer, along with the date.

## ✨ Key Features

* Automated question processing
* AI-generated educational responses
* Simple, student-friendly explanations
* Google Sheets integration
* Automated workflow using n8n

## ⚠️ Limitations

* AI-generated answers may occasionally be inaccurate and should be verified.
* The workflow depends on the availability and configuration of its connected services.
* This is a learning and portfolio project, not a production-ready student support service.
